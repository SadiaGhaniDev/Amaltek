# Amaltek LLC Website

A static, single-page company website. No framework, build step, backend, tracking, or form submission.

## Open and edit

Open `dist/index.html` in a browser. For local HTTP preview, run `python3 -m http.server 8000 --directory dist`, then visit `http://localhost:8000`.

- Content: `dist/index.html`
- Design and responsive rules: `dist/styles.css`
- Mobile menu and copyright year: `dist/script.js`
- Logo, favicon, and hero illustration: `dist/assets/`

Deploy the contents of `dist` to a static host after choosing a provider. Hosting and domain setup are not configured yet.

## Before launch

Confirm the mailbox info@amaltek.com works, review content and the logo, and verify the deployed site at its final domain. No claims about certifications, clients, or project counts are included. The website does not collect visitor data or submit forms.

## Appearance

Light and dark themes follow the system preference initially. The header toggle remembers a manual selection in browser local storage. A separate light-colored logo is displayed on dark backgrounds. This preference is device-local and requires no backend.
